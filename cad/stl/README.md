# STL files

Export one STL per printed part from the native SolidWorks file (Save As → STL, units mm, resolution Fine). File name = part name:

OUTER_SHELL.stl · OUTER_CAP.stl · INNER_MOUNT.stl · RETAINER.stl · ADAPTER.stl · ADAPTER_CAP.stl · CLAMP.stl · PUSH.stl

Check each file in a slicer (PrusaSlicer/Cura) before committing: correct scale, manifold, no missing faces.
