# **README**

## STL files (3D printing)

One STL per printed part, named exactly like the native part (units mm, resolution Fine):

`OUTER_SHELL.stl · OUTER_CAP.stl · INNER_MOUNT.stl · RETAINER.stl · ADAPTER.stl · ADAPTER_CAP.stl · CLAMP.stl · PUSH.stl · RUBBER_COVER.stl (TPU/silicone, if printed)`

Only custom parts belong here. Purchased parts (motor, bearing, battery, driver board, button, screws) are not printed and their vendor geometry is not redistributed — see `../third_party/README.md`.

Check each file in a slicer (PrusaSlicer/Cura) before committing: correct scale, manifold, no missing faces. Print settings: `../../docs/manufacturing.md`.
